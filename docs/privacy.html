개인정보처리방침

1. 처리하는 정보와 목적

계정과 로그인

Apple 로그인에서 제공되는 사용자 식별자, 이름, 이메일(이메일 가리기를 선택하면 Apple의 중계 이메일), 인화의 계정 식별자와 인증 정보를 계정 생성·인증·접근권한 확인에 사용합니다. Apple 계정 비밀번호는 인화가 수집하지 않습니다.

사용자가 선택하거나 입력하는 기록

사진·영상, 촬영일, 메모, 촬영 장소의 이름·주소·좌표, 함께한 사람 태그, 스페이스 이름·프로필 사진과 멤버 관계를 보관·조회·공유·내보내기에 사용합니다. 사진·영상 원본에 촬영일, 위치 등 메타데이터가 포함될 수 있습니다. ‘함께한 사람’은 스페이스 멤버 관계이며 iPhone 연락처 주소록을 읽는 기능이 아닙니다.

권한과 선택적 기능

  • 사진·영상 가져오기: 시스템 선택기에서 고르거나 공유시트로 명시적으로 전달한 항목을 사용합니다.
  • 사진 앱 추가: 내보내기를 요청할 때 저장 권한을 사용합니다.
  • 카메라: 초대 QR 인식에 사용합니다. 카메라 영상 자체를 서버에 업로드하는 기능은 아닙니다.
  • 위치: 허용한 경우 주변 장소 검색과 거리 표시에 사용합니다. 저장한 촬영 장소의 좌표는 기록의 일부로 서버에 보관됩니다. 이동 경로를 지속적으로 추적하지 않습니다.

선택 권한을 거부해도 해당 기능 이외의 이용은 가능합니다. 초대 코드는 직접 입력할 수 있고 장소도 수동으로 지정할 수 있습니다.

연결·문의 정보

서비스 접속 과정에서 IP 주소, 요청 시각, 오류와 인증·보안 관련 로그가 인프라 제공자에게 처리될 수 있습니다. 이는 연결 제공, 장애 대응과 부정 이용 방지를 위한 것입니다. 문의·신고 시 이메일 주소, 메시지와 사용자가 보낸 증빙을 응답·문제 해결·권리 보호에 사용합니다.

광고 추적, 교차 앱 추적, 광고 목적의 개인정보 판매, 별도 이용행태 분석 SDK를 사용하지 않습니다. 앱의 장소 검색 결과 수 등 일부 진단값은 기기 내부에만 저장합니다.

2. 스페이스 공유 범위

기록과 미디어는 같은 스페이스의 멤버가 열람하고 내려받을 수 있습니다. 멤버에게 표시 이름과 역할, 함께한 사람 등의 정보가 표시됩니다. 초대받아 새로 참여한 사람도 기존 기록을 볼 수 있습니다.

초대 QR과 코드는 참여 권한을 전달하는 수단이므로 공개 게시하지 마세요. 공유는 공개 피드 방식이 아니지만, 상대방이 이미 저장하거나 외부로 전달한 사본까지 인화가 통제할 수는 없습니다.

운영자는 서비스 운영·장애 대응·신고 처리 등에 필요한 범위에서 데이터에 접근할 수 있습니다. 법령에 따른 요청, 별도 동의 또는 이 방침에서 설명한 서비스 제공 외의 목적으로 임의 제공하지 않습니다.

3. 외부 서비스와 처리위탁

  • Supabase: 계정 인증, 데이터베이스, 비공개 미디어 저장소와 서버 함수 운영을 맡습니다. 앱의 주 저장 리전은 대한민국 서울입니다. 계정 정보, 기록·미디어, 멤버 관계 및 서비스 요청 정보가 처리됩니다. 데이터 처리 부속약정 · 하위 처리업체 안내
  • Apple: Apple 로그인, 지도·장소 검색, 사진 선택·내보내기와 QR 인식에 시스템 서비스를 사용합니다. 서비스별 정보 처리에는 Apple 개인정보 처리방침도 적용됩니다.
  • Google Gmail: 사용자가 문의·신고 이메일을 보내면 이메일 주소, 메시지와 첨부파일이 메일 서비스에서 처리됩니다. Google 개인정보처리방침
  • GitHub Pages: 이 공개 안내 사이트를 호스팅합니다. GitHub가 보안 등을 위해 방문자의 IP 주소와 접속 정보를 처리할 수 있습니다. 이 사이트에는 별도 광고·분석 스크립트나 회원가입 기능이 없습니다. GitHub 개인정보처리방침

서울 저장 리전이 모든 처리가 국내에서만 이루어진다는 의미는 아닙니다. 해외 사업자의 인증·네트워크·메일·지원 서비스 및 하위 처리업체를 통해 국외 처리가 발생할 수 있습니다. 해당 서비스의 처리 지역과 보유 기준은 위 제공자 문서에 설명되어 있으며, 인화에 적용되는 상세 처리 사항은 아래 연락처로 요청할 수 있습니다.

웹 링크 가져오기를 사용하면 사용자가 공유한 웹사이트에 연결하여 미디어를 찾습니다. 해당 사이트는 IP 등 연결 정보를 처리할 수 있으며, 사이트 자체의 정책도 적용됩니다. 인화는 제3자 사이트의 접근 제한을 해제하거나 다운로드 권리를 부여하지 않습니다.

4. 보유 기간과 삭제

  • 계정·기록: 서비스 제공에 필요한 동안 보관하며, 계정 또는 해당 데이터의 삭제가 완료되면 운영 데이터베이스와 저장소에서 삭제합니다.
  • 로그아웃: 기기의 로그인 상태를 종료하며 서버의 계정이나 기록을 삭제하지 않습니다.
  • 스페이스 나가기: 멤버 관계를 해제하며, 해당 스페이스에 올린 기록은 남습니다.
  • 스페이스 삭제: 오너가 삭제하면 그 공간의 모든 멤버가 올린 기록·미디어와 초대·멤버 정보를 삭제합니다.
  • 계정 삭제: 내 계정과 내가 올린 데이터를 삭제합니다. 다른 멤버가 올린 기록은 유지하며, 남은 멤버가 있는 공간은 소유권을 이전하여 유지하고 남은 멤버가 없는 공간은 정리합니다.
  • 삭제 처리 기록: 중단된 삭제를 이어가기 위한 최소 정보는 완료까지 보관합니다. 계정 삭제 완료 영수증은 사용자 식별자와의 연결을 제거하며, 앱의 완료 수신 확인 후 30일이 지나면 정리 대상이 됩니다. 수신 확인 전에는 삭제 완료를 복구할 수 있도록 유지됩니다. 삭제된 스페이스에 데이터가 다시 업로드되는 것을 막기 위한 최소 식별자·처리 상태는 계속 보관되며, 요청자 계정 삭제 시 요청자 연결을 제거합니다.
  • 기기 사본: 업로드 대기 파일과 조회 캐시는 기기에 저장될 수 있습니다. 계정 삭제 과정에서 해당 계정의 로컬 데이터를 정리합니다. 사진 앱에 내보낸 파일이나 다른 사람의 사본은 별도로 삭제해야 합니다.
  • 문의·신고: 처리와 관련 분쟁 해결에 필요한 동안 보관하고 목적이 끝나면 지체 없이 삭제합니다. 법령상 보존 의무가 있는 경우 해당 항목을 그 의무 기간 동안 분리하여 보관합니다.

전자적 정보는 서비스의 데이터베이스·저장소 삭제 절차로 파기합니다. 인프라의 보안 로그나 백업 사본은 제공자의 보유·순환 정책에 따라 제거될 수 있어 운영 데이터 삭제와 모든 인프라 사본의 삭제 시점이 같지는 않을 수 있습니다. 서버 장애 등으로 삭제가 중단되면 앱의 재개 기능 또는 고객지원을 이용해주세요.

5. 이용자의 권리와 행사 방법

개인정보 열람, 정정·삭제, 처리정지 및 동의 철회는 jxewon.kim@gmail.com로 요청할 수 있습니다. 본인 또는 적법한 대리인인지 확인하는 데 필요한 최소 정보를 요청할 수 있으며, 법령상 제한 사유가 있는 경우 이유를 안내합니다.

계정 삭제는 스페이스 → 설정(톱니바퀴) → 계정 설정 → 계정 삭제에서 시작합니다. 시스템 권한은 iPhone 설정에서 철회할 수 있습니다. 필수 계정 처리에 동의하지 않거나 처리를 중단하면 로그인 기반 보관·공유 서비스 제공이 제한될 수 있습니다.

미성년자의 개인정보도 같은 기준으로 보호합니다. 법정대리인 동의가 필요한 개인정보 처리가 동의 없이 이루어진 사실을 알게 되면 보호자 또는 이용자는 위 연락처로 알려주세요. 확인 후 필요한 보호·삭제 조치를 안내합니다.

6. 보호 조치

서버 연결에는 HTTPS를 사용하고, 로그인 및 스페이스 멤버십에 따라 데이터 접근을 제한합니다. 미디어 저장소는 비공개이며 만료되는 접근 링크를 사용합니다. 이는 종단간 암호화 서비스라는 뜻은 아닙니다. 초대 코드나 접근 링크를 다른 사람에게 노출하지 않도록 주의해주세요.
